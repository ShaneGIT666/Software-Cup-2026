## 使用规则

- 保留生成报告及其 JSON 原样，避免通过改写结果制造新的历史事实。
- 引用时必须同时写明生成日期、提交、数据集、配置、工作区状态和已知失败指标。
- 报告只能比较旧原型算法或发现回归，不能证明目标 PostgreSQL、effective-only、授权过滤、真实 Provider 或生产降级链路已经验收。
- 建立新的当前基线时，必须在干净工作区重新运行、固定数据集和依赖、记录完整命令，并在 `docs/change-log/` 新增日志和更新索引。
- 新报告不得覆盖旧文件；文件名包含日期、模式和必要的版本标识。
