## 5. 后续开发计划入口

当前任务看板用于管理开工前任务，后续阶段性开发执行以 `development-plan.md` 为主线，并按 `model-task-classification.md` 将任务分为重点任务、普通任务和人工确认任务。

已纳入计划的近期重点：

1. 复审当前前后端 MVP 骨架与 API 契约是否一致。
2. 将案例提交和审核从临时响应升级为可持久化流程。
3. 补齐审核演示路径、图片上传状态和端到端演示检查清单。
4. 对检索排序、模型适配、国产化部署和答辩材料进行重点复审。
