## 10. 多模态诊断测试

新增 `tests/test_multimodal_cross_modal_signals.py`，覆盖：

1. 返回 `multimodalSignals`。
2. OCR / 视觉线索进入 queryContext。
3. provider fallback 不返回 500。
4. citation 包含 `crossModalMatchMode`。
5. 图片线索不进入 Evidence Pack 正式证据。
6. pending/rejected 仍不进入检索结果。

## 11. RAG feedback 测试

新增 `tests/test_rag_feedback_review_flow.py`，覆盖：

1. 创建后默认 `pending_review`。
2. approve 后状态为 approved。
3. reject 后状态为 rejected。
4. approved feedback 进入知识关系网络。
5. pending/rejected 不进入知识关系网络。
6. 原 RAG 接口仍返回 `complianceChecks`。
7. 无 correctedAnswer 时必须填写 labels 或 reason。
