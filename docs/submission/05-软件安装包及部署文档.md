# 软件安装包及部署文档

项目名称：设备检修知识检索与作业辅助系统
版本日期：2026-06-27

## 1. 安装包说明

源码仓库包含后端、前端源码、测试、部署脚本和文档。正式安装包可在源码外单独生成，不建议把构建产物、视频、截图、上传资料或 `.env` 提交到源码仓库。

## 2. 安装包目录结构

建议提交包结构：

```text
Software-Cup-2026/
  backend/
  frontend/
  data/examples/
  docs/
  scripts/
  tests/
  Dockerfile
  README.md
  .env.example
```

如比赛需要单独安装包，可另放：

```text
release/
  frontend/dist/
  backend/
  scripts/
  README.md
```

## 3. 不包含内容说明

源码仓库不得包含：

- `.env`
- API Key
- `.venv`
- `node_modules`
- `frontend/dist`
- `data/uploads` 运行数据
- `data/knowledge` 运行数据
- 官方 PDF、截图、视频、压缩包、临时日志、PID

## 4. 环境要求

| 项 | 要求 |
|---|---|
| OS | Windows 开发环境；LoongArch / 银河麒麟目标环境 |
| Python | 3.11 推荐 |
| Node | 20.x 推荐 |
| Docker | 可选，目标环境可用时优先 |
| 模型服务 | OpenAI-compatible 文本 LLM 可选 |

## 5. Windows 本地开发启动

```powershell
.\start-dev.bat
```

或分别启动：

```powershell
cd backend
..\backend\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --reload
cd frontend
npm.cmd run dev
```

## 6. LoongArch / Kylin 部署

推荐先执行：

```bash
bash scripts/loongarch-final-verify.sh
```

如果 Docker 不可用，使用 Python venv + FastAPI 静态托管 `frontend/dist`。默认配置应保持 offline/mock 和 SQLite fallback 可运行。

## 7. Docker 部署

目标环境生成前端 dist 后执行：

```bash
bash scripts/loongarch-final-verify.sh --docker
```

脚本会构建镜像、运行容器、检查 `/api/health`、`/api/providers/status` 和首页，并清理容器。

## 8. offline/mock 演示部署

默认兜底配置：

```env
REMOTE_API_MODE=off
LLM_PROVIDER=mock
MULTIMODAL_PROVIDER=mock
OCR_PROVIDER=mock
RAG_VECTOR_STORE=sqlite
RAG_VECTOR_SQLITE_ENGINE=python_scan
RAG_VECTOR_ENHANCER=off
RAG_VECTOR_FALLBACK_LOCAL=on
```

该模式不需要 API Key 和外网。

## 9. 真实 LLM 配置

示例：

```env
REMOTE_API_MODE=auto
LLM_PROVIDER=openai
OPENAI_BASE_URL=https://maas-api.cn-huabei-1.xf-yun.com/v2
OPENAI_API_STYLE=chat_completions
OPENAI_MODEL=xopqwen36v35b
OPENAI_API_KEY=请在目标环境填写，不要提交
```

验证接口：

```text
GET /api/providers/status
POST /api/providers/llm/validate
POST /api/rag/answer
```

## 10. 常见问题

| 问题 | 处理 |
|---|---|
| 无外网或无 Key | 使用 `REMOTE_API_MODE=off` |
| Chroma 安装失败 | 保持默认 SQLite / python_scan |
| sqlite-vec 不可用 | 使用 python_scan |
| 真实 OCR 不可用 | 使用 mock/OCR fallback |
| 前端 dist 缺失 | 在可用 Node 环境先执行 `npm run build` |

## 12. 卸载与清理

1. 停止 FastAPI、Vite 或 Docker 容器。
2. 删除运行时 `.env`。
3. 按需要清理 `data/uploads`、`data/knowledge`、临时日志和 release 包。
4. 不删除源码仓库中的 `data/examples` 和文档。

## 13. 安全注意事项

API Key 只允许写入目标环境未提交的 `.env` 或进程环境变量。演示视频和截图中应遮挡 Key。官方 PDF、来源不明维修资料和运行数据不得进入源码仓库。
