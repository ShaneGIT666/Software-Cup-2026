项目名称：设备检修知识检索与作业辅助系统

版本日期：2026-06-27

## 1. 部署目标

系统支持本地开发、Docker 演示和 LoongArch / 银河麒麟目标环境部署。默认策略是主链路可运行，增强能力可配置，失败时自动或手动降级到离线兜底。

## 2. 依赖

- Python 3.11 或目标环境可用 Python。
- Node.js，用于前端构建。
- FastAPI 后端依赖。
- 可选：真实 LLM provider、MinerU、OCR provider、向量增强组件。

## 3. 前端构建

```powershell
cd frontend
npm.cmd install
npm.cmd run build
```

构建产物位于 `frontend/dist`，该目录不提交 Git。

## 4. 后端启动

```powershell
.\backend\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

如果开启 FastAPI 静态托管，可通过后端地址访问前端页面。

## 5. 配置方式一：手动 `.env`

离线演示模式：

```env
REMOTE_API_MODE=off
LLM_PROVIDER=mock
MULTIMODAL_PROVIDER=mock
OCR_PROVIDER=mock
RAG_VECTOR_FALLBACK_LOCAL=on
```

真实 LLM 模式：

```env
REMOTE_API_MODE=auto
LLM_PROVIDER=openai
OPENAI_BASE_URL=<base-url>
OPENAI_API_STYLE=chat_completions
OPENAI_MODEL=<model>
OPENAI_API_KEY=<secret>
LLM_TIMEOUT_SECONDS=60
RAG_USE_STRUCTURED_LLM_ANSWER=true
```

## 6. 配置方式二：初始化脚本

Windows：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\init-config.ps1
```

Linux / Kylin / LoongArch：

```bash
bash scripts/init-config.sh
```

脚本行为：

- 支持离线演示模式和真实 LLM 模式。
- 覆盖 `.env` 前自动生成 `.env.backup.<timestamp>`。
- 检查 `.gitignore` 是否忽略 `.env`。
- API Key 只脱敏显示。
- 输出启动命令、验证方式和恢复离线模式命令。

恢复离线模式：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\init-config.ps1 -Mode offline -Force
```

或：

```bash
bash scripts/init-config.sh --mode offline --force
```

## 7. 验证模型服务

Windows：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\validate-provider.ps1
```

Linux / Kylin / LoongArch：

```bash
bash scripts/validate-provider.sh
```

也可以访问：

```text
GET /api/providers/status
```

系统状态页会展示模型服务、OCR、多模态、向量检索和离线兜底状态。

## 8. LoongArch / 银河麒麟复验

推荐在目标环境执行：

```bash
bash scripts/loongarch-final-verify.sh
```

如需要 Docker 路径：

```bash
bash scripts/loongarch-final-verify.sh --docker
```

若 Docker 不可用，可使用 Python venv + FastAPI 静态托管作为兜底。

## 9. 不进入交付包的内容

不要提交或打包：

- `.env`
- API Key
- `.venv`
- `node_modules`
- `frontend/dist`
- `data/uploads`
- `data/knowledge`
- 日志、截图、视频、压缩包和运行缓存

## 10. 部署风险边界

真实 LLM、OCR、多模态、MinerU 和向量增强均依赖目标环境可用性。若目标环境无法稳定运行某项增强能力，应切换为离线演示模式或本地轻量检索兜底，并在答辩中如实说明。
