产品名称：设备检修知识检索与作业辅助系统

版本日期：2026-06-27

## 1. 产品简介

本系统面向设备检修现场，帮助一线人员按步骤完成故障描述、参考依据查看、智能检修建议生成、回答复核修正和经验提交。系统同时提供管理中心用于资料入库、审核和知识沉淀，并提供系统状态页用于部署复验和答辩展示。

## 2. 如何进入检修助手

打开系统后默认进入“检修助手”。顶部导航包含：

- 检修助手。
- 管理中心。
- 系统状态。

检修助手是默认首页，适合一线人员直接开始一次检修辅助。

## 3. 五步完成检修辅助

1. 描述故障：输入设备型号、故障现象和检修等级。可点击“使用演示样例”快速填入示例数据。
2. 查看依据：点击“开始诊断”后查看参考依据。系统仅使用已审核资料生成正式建议。
3. 生成指引：点击“生成智能检修建议”，查看初步判断、检查步骤、维修步骤、安全提醒、验收标准、引用来源和不确定信息。
4. 复核修正：如果发现建议不准确或缺少安全提醒，可提交回答标注/修正。修正默认进入待审核。
5. 提交经验：填写故障原因、处理方法、处理结果和经验标签，提交后进入审核。

## 4. 图片识别线索

在“描述故障”区域可以上传现场故障图片。系统会提取 OCR 文本、视觉现象、识别部件和图片线索。图片线索用于增强当前检索上下文，正式建议仍基于已审核资料。

## 5. 管理中心

管理中心面向管理员、班组长和知识维护人员，包含：

- 资料入库：上传维修手册、现场资料、PDF、Office、Markdown 和图片。
- 待审核内容：审核资料片段、维修案例和回答修正。
- 审核记录：查看审核流水。
- 知识关系图：查看已审核知识之间的关系。

## 6. 知识关系图

知识关系图展示设备、故障、资料、案例、流程、术语和回答修正之间的关系。界面包含：

- 摘要统计。
- 图例。
- 轻量 SVG 图谱。
- 节点详情面板。
- 典型关系路径。
- 详细节点和关系列表。

说明：知识关系图仅展示已审核通过的内容，待审核和拒绝内容不会进入正式知识关系图。

## 7. 系统状态

系统状态页用于查看：

- 当前运行模式。
- 模型服务 provider、模型名、Key 是否配置。
- OCR 和多模态状态。
- 向量检索状态。
- 离线兜底状态。
- MinerU、Chroma、最近解析和最近索引。
- LoongArch / Kylin 适配说明。
- 初始化配置命令。

## 8. 初始化配置

Windows：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\init-config.ps1
```

Linux / Kylin / LoongArch：

```bash
bash scripts/init-config.sh
```

脚本支持离线演示模式和真实 LLM 模式。真实 LLM 模式需要输入 OpenAI-compatible base_url、模型名和 API Key。API Key 只写入本地 `.env`，不会提交到仓库，也不会完整打印到终端。

## 9. 常见说明

- 参考依据：系统从已审核资料、案例和手册中匹配出的依据。
- 仅使用已审核资料：待审核或被拒绝的内容不会进入正式建议。
- 离线兜底：真实模型不可用时，系统仍可使用本地演示能力完成流程。
- 人工复核：当证据不足或风险较高时，需要现场人员确认后再执行。
- 知识关系图：用于展示知识沉淀关系，不等同于完整工业图数据库平台。

## 10. 安全注意事项

不要把 `.env`、API Key、上传资料、运行知识库、日志、视频、截图或压缩包提交到源码仓库。演示截图中应遮挡账号、Key、内网地址和敏感文件路径。

## P0 补充：PDF 图示页入库说明

上传维修手册 PDF 后，系统会优先使用 MinerU 解析正文和图片资源。如果 MinerU 超时、不可用，或没有提取到图片资源，系统会自动生成“PDF 页面视觉资产”片段，供管理员在管理中心审核。

在资料卡中看到“PDF 页面视觉资产已生成”表示系统已经为 PDF 中的图示页建立了可审核片段。管理员可以在片段列表中查看 `PDF 页面视觉资产`，审核通过后再进入正式知识沉淀链路。

该 fallback 只保证演示和审核链路不断，不代表系统已经完成生产级图像理解；涉及维修参数和安全结论时仍需人工复核。
