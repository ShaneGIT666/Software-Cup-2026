# 软件产品说明书

产品名称：设备检修知识检索与作业辅助系统
版本日期：2026-06-27

## 1. 产品简介

本系统面向设备检修场景，提供资料检索、故障诊断、RAG 作业建议、资料入库、审核、案例沉淀、RAG 回答修正和知识关系网络展示能力。系统强调证据可追溯、审核后入库和 LoongArch / 银河麒麟目标环境可部署。

## 2. 适用场景

- 设备启动困难、异常振动、压力波动、温度异常等故障排查。
- 检修手册、现场记录、图片和案例混合查询。
- 一线经验审核后沉淀。
- 比赛答辩展示检索、RAG、审核和 fallback 闭环。

## 3. 用户角色

| 角色 | 操作 |
|---|---|
| 检修人员 | 检索资料、上传图片、生成作业指引、提交案例 |
| 审核人员 | 审核资料片段、案例和 RAG 回答修正 |
| 管理员 | 配置 provider、检查状态、执行部署验证 |

## 4. 运行环境

开发环境支持 Windows。最终交付环境面向 LoongArch CPU + 银河麒麟高级服务器操作系统。无真实模型或外网时可使用 offline/mock 模式完成主链路演示。

## 5. 功能入口说明

首页分为检索诊断、结果证据、作业流程、资料入库、RAG 建议、知识关系网络、案例提交、审核工作台和审计流水。

## 6. 检索诊断操作

1. 输入设备型号，例如“发动机-示例型号 A”。
2. 输入故障现象，例如“启动困难，怠速不稳”。
3. 选择检修等级。
4. 点击“开始检索”。
5. 查看命中证据、来源、分数和匹配原因。

## 7. 故障图片诊断操作

1. 在检索诊断面板点击“图片诊断”。
2. 上传 jpg、jpeg、png 或 webp 图片。
3. 查看 OCR 文本、视觉症状、识别部件、fallback 状态和匹配说明。
4. 系统会把图片线索合并到 queryContext，并用于增强 approved-only 检索。

## 8. RAG 作业指引查看

点击“生成检修建议”。系统输出：

- 初步判断
- 检修等级说明
- 作业前准备
- 建议检查步骤
- 建议维修步骤
- 作业中风险控制
- 合规校验提醒
- 安全提醒
- 验收标准
- 引用证据
- 不确定信息

## 9. 案例/经验总结提交

在案例面板填写故障原因、处理方案、处理结果、经验总结、教训复盘和标签。提交后默认进入 pending_review，审核通过后可被检索。

## 10. 审核工作台使用

审核工作台展示 pending_review 的案例、知识片段和 RAG feedback。审核通过进入 approved；拒绝时需填写原因。审核事件会进入审计流水。

## 11. 知识关系网络查看

点击“当前查询子图”或“全局图谱”。图谱展示设备、故障、手册、案例、资料、片段、术语、provider 和 RAG feedback 之间的关系。图谱默认只纳入 approved 对象。

## 12. RAG 回答标注/修正

在 RAG 面板点击“标注/修正本回答”，填写修正后的建议、标签、修正原因和提交人。提交后显示等待审核。审核通过后，修正记录进入轻量知识关系网络。

## 13. Provider / fallback 状态说明

系统状态展示 LLM、多模态、OCR、embedding、向量库、MinerU 和 fallback 情况。`REMOTE_API_MODE=off` 时强制使用本地兜底；`auto` 时优先尝试真实 provider，失败后回退。

## 14. 常见问题

| 问题 | 说明 |
|---|---|
| 没有 API Key 能否演示 | 可以，offline/mock 主链路可运行 |
| 图片诊断是否等于生产级视觉诊断 | 不是，当前是 OCR/多模态语义线索辅助检索 |
| hash embedding 是否等于真实语义向量 | 不是，它是 fallback |
| pending_review 是否会被 RAG 使用 | 不会，默认只检索 approved |

## 15. 注意事项

不要把 `.env`、API Key、上传资料、官方 PDF、截图、视频和压缩包提交到源码仓库。真实 LLM 更换 Key、base_url 或模型名后必须重新验证。
