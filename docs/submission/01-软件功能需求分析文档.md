项目名称：设备检修知识检索与作业辅助系统

版本日期：2026-06-27

## 1. 需求背景

设备检修资料通常分散在维修手册、现场记录、故障图片、历史案例和人员经验中。一线检修人员需要在有限时间内定位设备型号、故障现象、检修等级和安全要求对应的知识，并形成可追溯的作业建议。

本系统建设一个 PC Web 检修辅助工具，通过资料入库、审核、知识检索、多模态线索、标准作业步骤、智能检修建议和经验沉淀，帮助检修人员更快、更规范地完成检修工作。

## 2. 用户角色

| 角色 | 需求 |
| --- | --- |
| 一线检修人员 | 快速描述故障、查看依据、生成指引、提交经验 |
| 班组长 / 知识管理员 | 上传资料、审核内容、维护知识库 |
| 运维 / 答辩展示人员 | 查看模型服务、OCR、多模态、向量、fallback、部署状态 |

## 3. 功能需求

### 3.1 检修助手

- 支持输入设备型号、故障现象和检修等级。
- 支持上传现场图片并提取图片识别线索。
- 支持一键演示样例。
- 支持查看参考依据。
- 支持生成智能检修建议。
- 支持提交回答标注/修正。
- 支持提交处理经验。

### 3.2 多模态知识检索

- 支持文本、设备型号、故障描述和图片线索。
- 图片线索包括 OCR 文本、视觉现象、识别部件和模型分析摘要。
- 正式建议仅基于已审核资料。

### 3.3 标准化作业指引

- 输出检查步骤、维修步骤、安全提醒、合规校验和验收标准。
- 对 high / critical 风险提示人工复核。
- 引用来源可追溯到资料、片段、页码或章节。

### 3.4 知识沉淀与更新

- 上传资料默认进入待审核。
- 检修案例和回答修正默认进入待审核。
- 审核通过后进入正式知识库或知识关系图。
- 拒绝、废弃或替换内容不参与正式检索。

### 3.5 系统状态与部署

- 展示 LLM、OCR、多模态、embedding、MinerU、Chroma 和 fallback 状态。
- 支持初始化配置脚本，便于离线演示和真实 LLM 接入。
- 支持 LoongArch / 银河麒麟目标环境复验路径。

## 4. 非功能需求

- 不提交 API Key、`.env`、运行数据和上传资料。
- 真实模型不可用时应可降级演示。
- 前端界面适合 1920×1080 录屏。
- 文案应面向真实用户，减少默认首页技术词。

## 5. 边界说明

当前系统是比赛交付原型。跨模态能力表述为“故障图片经 OCR/多模态语义线索进入检索上下文”；知识关系图表述为“轻量知识关系网络原型”。不宣称完整工业图数据库平台或生产级图文向量检索平台。
