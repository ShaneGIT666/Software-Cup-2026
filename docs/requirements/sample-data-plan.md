样例数据决定演示质量。开发前期必须先准备一批结构清晰、能支撑完整演示路径的数据。

## 1. 第一批数据目标

MVP 阶段至少准备：

| 数据类型 | 数量 | 用途 |
| --- | --- | --- |
| 设备类型 | 1 到 2 类 | 限定演示范围 |
| 设备型号 | 3 个 | 支撑检索筛选 |
| 检修手册片段 | 10 条以上 | 支撑知识来源 |
| 故障案例 | 5 条以上 | 支撑案例检索 |
| 作业流程 | 3 条以上 | 支撑步骤化作业指导 |
| 故障图片 | 3 张以上 | 支撑多模态上传演示 |

## 2. 推荐设备场景

优先选择赛题给出的参考方向：

```text
摩托车发动机维修
```

原因：

1. 赛题明确给出参考手册，资料来源自然。
2. 故障类型直观，便于答辩评委理解。
3. 可构造启动困难、怠速不稳、异响、排气异常等典型场景。

备选场景：

1. 工业电机检修。
2. 液压泵站检修。
3. 生产线传送带设备检修。

## 3. 故障案例字段

每条案例建议包含：

| 字段 | 示例 | 是否必填 |
| --- | --- | --- |
| `id` | `case-001` | 是 |
| `deviceType` | `发动机` | 是 |
| `deviceModel` | `发动机-示例型号 A` | 是 |
| `faultTitle` | `启动困难` | 是 |
| `faultText` | `冷机启动困难，怠速不稳` | 是 |
| `symptoms` | `怠速波动、排气异常` | 是 |
| `possibleCauses` | `燃油供给不足、火花塞积碳` | 是 |
| `solution` | `检查燃油滤清器并更换火花塞` | 是 |
| `tools` | `万用表、火花塞套筒` | 否 |
| `safetyNotes` | `作业前确认设备停止运行` | 是 |
| `source` | `示例检修手册` | 是 |
| `status` | `approved` | 是 |
| `tags` | `启动困难、点火系统` | 是 |

## 4. 手册片段字段

每条手册片段建议包含：

| 字段 | 示例 |
| --- | --- |
| `id` | `doc-001` |
| `title` | `启动困难检查流程` |
| `deviceType` | `发动机` |
| `chapter` | `故障诊断` |
| `content` | `检查燃油供给、点火系统和进气系统。` |
| `sourceName` | `示例检修手册` |
| `page` | `15` |
| `tags` | `启动困难、燃油、点火` |

## 5. 作业流程字段

每条作业流程建议包含：

| 字段 | 示例 |
| --- | --- |
| `id` | `wf-001` |
| `title` | `发动机启动困难标准检查流程` |
| `deviceType` | `发动机` |
| `faultType` | `启动困难` |
| `level` | `常规检修` |
| `tools` | `万用表、压力表、火花塞套筒` |
| `safetyNotes` | `断电、通风、防火` |
| `steps` | 步骤数组 |
| `acceptanceCriteria` | `启动正常、怠速稳定、无异常报警` |

## 6. 数据存放建议

| 路径 | 内容 |
| --- | --- |
| `data/manuals/` | PDF、手册片段、资料来源 |
| `data/examples/` | JSON/CSV 样例数据 |
| `data/uploads/` | 开发期上传文件 |

## 7. 数据准备分工

| 任务 | 负责人 | 完成标准 |
| --- | --- | --- |
| 收集或整理手册资料 | C | 至少 1 份可引用资料 |
| 设计样例数据结构 | B | 字段满足检索和作业流程 |
| 准备演示案例 | B/C | 至少 5 条案例 |
| 准备前端展示样例 | A | 页面 mock 数据够用 |
| 核对数据与演示脚本 | 全员 | 演示路径无断点 |
