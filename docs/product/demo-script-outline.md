# 演示脚本大纲

本文档用于提前设计比赛演示路径。功能开发时优先保证这条路径稳定。

详细逐步检查清单见：`docs/product/demo-checklist.md`。

## 1. 演示目标

在 3 到 5 分钟内展示系统如何解决设备检修中的核心问题：

1. 检修知识分散，现场人员难以快速查询。
2. 作业步骤依赖经验，容易漏项或不规范。
3. 维修案例难以沉淀，新人复用困难。
4. 大模型可结合手册、案例和现场输入生成辅助建议。

## 2. 推荐演示故事

场景：

```text
一线检修人员接到设备异常反馈：发动机启动困难，怠速不稳，并伴随排气异常。
```

演示步骤：

1. 打开系统工作台。
2. 输入设备型号和故障现象。
3. 系统返回相关手册片段、历史案例和诊断建议。
4. 上传检修资料并展示资料入库状态。
5. 生成 Mock RAG 辅助建议，展示引用来源。
6. 点击相关结果进入标准作业指导。
7. 展示工具清单、安全提醒、逐步检查流程。
8. 上传一张故障图片，展示多模态入口。
9. 提交本次维修经验案例。
10. 切换审核员视角，通过案例。
11. 再次检索，展示新案例已经沉淀到知识库。

## 3. 演示亮点

| 亮点 | 展示方式 |
| --- | --- |
| 多模态输入 | 文本 + 图片上传入口 |
| 知识来源可追溯 | 检索结果显示手册名称、章节、页码 |
| 标准化作业 | 步骤、工具、安全提醒、验收标准 |
| 知识沉淀 | 案例提交、审核、入库 |
| 模型降级稳定 | 没有模型 API 时仍返回可解释建议 |
| 国产化适配意识 | 部署文档说明 LoongArch 和银河麒麟适配 |

## 4. 演示兜底方案

为避免答辩现场异常，必须准备：

1. 固定样例数据。
2. 模拟模型响应。
3. 本地截图备用。
4. 本地运行说明。
5. 预录演示视频。
