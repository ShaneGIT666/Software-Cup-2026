# 本地演示运行手册

适用范围：本地开发/录屏/赛前自检。  
不包含 PPT 和汇报讲稿。

## 1. 演示目标

稳定展示以下闭环：

```text
资料入库 -> pending_review 可见与片段修正 -> 多模态分析 -> 知识检索已审核知识 -> RAG 引用回答 -> 作业流程 -> 知识关系网络 -> 案例提交与审核 -> 新案例可检索
```

## 2. 启动前检查

执行：

```powershell
git status --short --branch
powershell -ExecutionPolicy Bypass -File .\scripts\run-local-verification.ps1
```

要求：
1. 工作区无非预期改动。
2. 后端测试通过。
3. 前端构建通过。
4. 不存在 `.env`、官方 PDF、`data/uploads/`、`data/knowledge/` 被暂存的情况。

## 3. 推荐演示资料

稳定文本资料：

```text
摩托车发动机无法启动时，应检查火花塞、高压包和燃油供给。若怠速不稳，应检查进气管路密封和怠速控制部件。检修前确认发动机冷却，并佩戴护目镜和防护手套。
```

官方 PDF：

```text
E:/Download/Downloads/摩托车发动机维修手册.pdf
```

注意：官方 PDF 不得提交进 Git。若 PDF 页数或网络成本不适合真实 API 分析，使用 mock provider 完成演示。

## 4. 固定输入

设备型号：

```text
发动机 示例型号 A
```

故障现象：

```text
启动困难，怠速不稳，排气异常
```

案例提交：

```text
原因：火花塞积碳
方案：清理并更换火花塞，复查燃油滤清器
结果：启动恢复正常，怠速稳定
标签：启动困难, 点火系统, 火花塞
```

## 5. 演示步骤

1. 运行 `dev start`。
2. 运行 `dev verify` 确认后端健康检查和前端首页可访问。
3. 打开 `http://127.0.0.1:5173/`。
4. 确认首页自动检索并显示结果。
5. 上传 Markdown/TXT 资料，确认显示 `待审核` 和 chunk 数；说明自动解析结果审核通过前不参与正式检索。
6. 上传官方 PDF 或图片，确认显示 `待多模态分析`。
7. 点击“多模态分析”，确认摘要、关键部件和 chunks 生成。
8. 打开片段修正入口，展示 pending_review 片段可查看、可人工修正并生成 revision；不要宣称当前已有资料片段 approve/reject 工作台。
9. 使用固定输入再次检索，展示已审核种子手册/案例的来源、命中词、原因和评分解释。
10. 点击“生成辅助建议”，展示 RAG answer 和 citations。
11. 点击检索结果中的流程，展示工具、安全提醒、步骤和验收标准。
12. 点击“生成关系网络”，展示设备、故障、已审核资料、案例、流程之间的关系。
13. 提交维修案例。
14. 在审核区通过案例。
15. 再次检索，展示新案例进入知识沉淀结果。

## 6. 兜底策略

| 问题 | 处理 |
| --- | --- |
| 真实 LLM Key 未配置 | 使用 mock provider，强调系统具备可替换适配层 |
| 官方 PDF 解析不稳定 | 先用 TXT/Markdown 演示稳定链路，再演示 PDF 上传与 mock 多模态分析 |
| 浏览器无法访问 localhost | 使用后端测试和前端构建作为替代验证，排查代理/插件/端口占用 |
| 资料检索未命中 | 确认资料片段是否仍为 `pending_review`；当前演示检索优先使用已审核种子手册/案例 |
| 审核区为空 | 先提交一条案例，再刷新审核列表 |

## 7. 禁止事项

1. 不要把 mock 多模态分析说成真实 OCR。
2. 不要把轻量关系网络说成生产级知识图谱。
3. 不要把后端最小依赖和 Docker 一体化验证扩大为所有增强依赖、真实 MinerU/OCR/Chroma 都已在 LoongArch + 银河麒麟生产级验收。
4. 不要把官方 PDF、`.env` 或运行时上传文件加入 Git。

## 8. 弱网兜底开关

比赛现场或录屏环境网络不稳定时，优先使用本地兜底链路：

```env
REMOTE_API_MODE=off
LLM_PROVIDER=mock
MULTIMODAL_PROVIDER=mock
```

效果：

1. 系统不会访问外网 API。
2. RAG 与多模态分析会返回 `provider=mock`、`fallback=true` 和明确的 `fallbackReason`。
3. 前端顶部状态条会显示“离线兜底模式”，演示仍可完成资料入库、检索、RAG 引用回答、作业流程、知识关系和案例审核闭环。

恢复云端增强时改回：

```env
REMOTE_API_MODE=auto
```

注意：`auto` 只表示允许尝试真实 API；真实可用性仍取决于 Key、网络、额度、模型限制和请求大小。
