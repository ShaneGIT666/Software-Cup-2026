# 7 分钟最终演示脚本

版本日期：2026-06-27

## 0:00-0:30 赛题痛点与系统定位

设备检修资料分散在手册、现场记录、图片和经验中。一线人员需要快速找到可信依据、生成标准作业指引，并把经验沉淀回来。本系统提供 PC Web 检修助手、管理中心和系统状态三类入口。

## 0:30-1:00 打开检修助手

打开系统后默认进入“检修助手”。说明五步链路：描述故障、查看依据、生成指引、复核修正、提交经验。点击“使用演示样例”，快速填入设备型号和故障现象。

## 1:00-1:50 描述故障和上传图片

展示设备型号、故障现象、检修等级。可上传现场图片，系统提取 OCR、视觉现象、识别部件和图片识别线索。

## 1:50-2:40 查看参考依据和图片识别线索

点击“开始诊断”，展示参考依据。强调正式建议只使用已审核资料，未审核内容不会进入检修依据。

## 2:40-3:40 生成智能检修建议

点击“生成智能检修建议”，展示初步判断、检查步骤、维修步骤、安全提醒、验收标准、引用来源和不确定信息。说明高风险内容必须人工复核。

## 3:40-4:30 回答标注/修正

打开“回答标注 / 修正”，填写修正建议、标签和原因。说明修正默认进入待审核，审核通过后进入知识关系图，不会直接污染正式检索依据。

## 4:30-5:20 提交处理经验

填写故障原因、处理方法、处理结果和经验标签，提交处理经验。说明案例审核通过后会沉淀到知识库。

## 5:20-6:10 管理中心

切换到管理中心，展示资料入库、待审核内容、审核记录和知识关系图。重点展示图谱摘要、图例、SVG 网络图、节点详情、典型关系路径和 approved-only 说明。

## 6:10-6:40 系统状态

切换到系统状态，展示模型服务、OCR、多模态、向量检索、离线兜底和初始化脚本说明。说明真实 LLM 通过 OpenAI-compatible 配置接入，Key 只写本地 `.env`。

## 6:40-7:00 总结

总结系统闭环：多模态线索、approved-only 检索、标准作业指引、人工审核、知识沉淀、真实模型接入和国产化环境部署兜底。

## P0 补充口播：PDF 图示页 fallback

在管理中心资料入库环节补充一句：维修手册中大量火花塞、起动电机、发动机拆装、气缸活塞等图示页，即使 MinerU 超时或没有提取到图片 assets，系统也会生成 PDF 页面视觉资产片段，先进入 pending_review 审核链路，避免官方 PDF 上传后显示 0 个图片片段。
