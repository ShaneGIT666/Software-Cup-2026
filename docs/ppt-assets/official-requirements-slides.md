# PPT 素材：官方要求对应页

## 一句话定位

设备检修知识检索与作业辅助系统，围绕“资料入库、审核隔离、知识检索、标准作业、RAG 建议、案例沉淀”形成闭环。

## 官方要求映射

1. 多模型服务：支持 OpenAI-compatible 云端 Qwen，mock 仅兜底。
2. 多模态检索：支持设备型号、文本故障、现场图片输入。
3. 标准作业指引：按检修等级输出准备、检查、维修、安全、验收、合规校验。
4. 知识沉淀：案例/经验、OCR/图片分析、文档片段全部先 pending_review，审核通过后可检索。

## 推荐讲法

我们没有把系统做成普通 RAG Demo，而是把“证据来源、审核状态、作业等级、人工修正、降级能力”作为主链路的一部分。
