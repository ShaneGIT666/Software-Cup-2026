1. 本系统不是简单问答，而是审核态知识库驱动的检修辅助闭环。
2. pending_review 隔离是生产级关键点，避免未审核资料污染检修建议。
3. 图片诊断用于提取线索，正式证据必须来自 approved 知识片段。
4. 检修等级影响作业前准备、风险控制、合规校验和人工复核提示。
5. 真实 LLM 接入后用于增强表达和推理，失败时仍有检索结果和标准模板。
6. LoongArch/Kylin 环境中不可运行的增强依赖不会硬撑，必须有替代路线或 fallback。
